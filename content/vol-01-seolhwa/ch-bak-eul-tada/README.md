# 박을 타다

흥부와 놀부를 한지 위의 연주로 각색한 인터랙티브 작품. 짧게 두드리면 소리가 나고, 1.05초 이상 눌렀다 놓으면 박이 갈라져 쌀·비단·먹 장난꾸러기가 나옵니다.

## 체험

- `index.html`을 로컬 HTTP 서버에서 열고 **이야기 펼치기**를 누릅니다.
- 흥부 장면: 화면 또는 Space를 약 2.2초 누르면 치료가 완료됩니다. 결과를 잠시 본 뒤 **제비를 떠나보내기**로 계속합니다.
- 씨앗 장면: 화면 또는 Space로 다음 장면을 시작합니다.
- 박 장면: 박을 터치하거나 A/S/D를 누릅니다. 짧게는 연주, 길게 눌렀다 놓기는 박 열기입니다. 화면 아래 버튼으로도 조작할 수 있습니다.
- 흥부의 박 세 개를 모두 열면 풍요 장면으로 이어집니다. **놀부의 이야기로** 버튼으로 계속합니다.
- 놀부 장면은 행동 전 → 다리를 꺾는 순간 → 행동 후로 이어집니다. 결과를 잠시 본 뒤 **다음 봄으로**를 누릅니다. 상해를 관객이 수행하는 조작은 없습니다.
- 놀부의 박 세 개를 열면 **소동을 마무리하기**로 마지막 장면에 갑니다.
- 씨앗 또는 **자유롭게 연주하기**를 누르면 박이 다시 여무는 자유 연주가 시작됩니다.
- 처음 화면의 **연주 듣기**은 자유 연주 화면을 열고 선택한 곡을 즉시 시작합니다. **자유롭게 연주하기**는 직접 연주할 화면만 엽니다.
- 곡 선택: 「작은 봄」「제비의 춤」「박 타는 잔치」「놀부의 소동」「달빛 아래 한지」. 모두 약 1분 길이의 창작곡이며 곡을 바꾸면 이전 연주를 멈춥니다. 곡마다 음계·장단·악구·먹 색을 달리하고, 실제 재생 시간을 표시합니다.
- 자유 연주에서는 세 박이 낮은·중간·높은 음역을 맡고, 각각 5음계를 순회합니다. **한 곡 들려주기** 또는 P로 선택한 곡을 듣거나 멈출 수 있습니다. 직접 연주를 겹칠 수 있으며, 도움말·숨긴 탭에서는 쉬고 처음·음소거에서는 자동 연주가 종료됩니다.
- Space: 이야기 시작, 치료(길게), 씨앗, 표시된 다음 장면 버튼을 진행합니다. 전환 중 입력과 키 자동 반복은 다음 장면을 건너뛰지 않습니다. 박 연주는 A/S/D로 계속할 수 있습니다.
- M: 소리, 체험 안내: 움직임 줄이기. 도움말이 열리거나 탭이 숨겨지면 진행과 오디오가 멈추고 누르던 입력이 취소됩니다.

## 구성

- `model.js`: 시간 기반 이야기 상태와 입력 계약. 프레임당 최대 진행량을 제한합니다.
- `paint.js`: Canvas 2D. 한지·넝쿨·제비·입자·비단·먹 도형은 절차적 렌더링입니다. 박은 텍스처를 가진 개별 스프라이트이며 갈라지는 두 부분을 별도로 변형합니다.
- `assets/images.js`: AI 생성 박과 손 장면 재료를 data URI로 포함합니다. 전체 스토리보드 이미지를 배경으로 재생하지 않습니다.
- `assets/story-images.js`의 치료 전·놀부 행동 후 재료와 기존 손 그림을 교차 전환합니다. 흰 배경 재료는 multiply 합성으로 한지와 어우러집니다. 화면 진입·미세한 움직임·덧그리는 붕대는 실시간이지만 손가락별 관절 애니메이션은 아닙니다.
- `transition.js`: 큰 장 사이를 잇는 절차적 먹 붓질. 화면을 덮은 순간 장면을 교체하고, 전환 중 입력과 이야기 시간을 멈춥니다. 치료·놀부 행동의 연속 장면에는 적용하지 않습니다. 움직임 줄이기에서는 짧은 페이드로 대체합니다.
- `tracks.js`: 5개 창작곡의 악구·선율·반주·음계·색 구성. 외부 음원이나 유명곡 채보를 포함하지 않습니다.
- `music.js`: 곡 선택과 자동 연주, 수동 음계 선택. AudioContext 시계에 0.1초 앞서 예약하고, 실제 발음 시점에 박과 버튼을 반응시킵니다.
- `sound.js`: Web Audio 합성 타악음·현악기풍 음색·짧은 잔향. 실제 국악기 녹음은 아닙니다. 동시 소스 수 제한과 컴프레서를 적용합니다.
- `app.js`: DOM·포인터·키보드·오디오와 이야기 연결. 외부 요청, 저장소, 부모 페이지 접근 없음. classic scripts와 내장 이미지로 `sandbox="allow-scripts"` 지원.

새 의존성을 설치하거나 빌드할 필요가 없습니다. 렌더링 픽셀 비율은 최대 1.7, 가로 내부 해상도는 최대 2200픽셀입니다. 색먹 번짐·꽃잎·금빛·넓은 비단이 타격과 개방에 반응합니다. 입자·띠·먹 도형 수를 제한합니다.

## 검사

```sh
node --test model.test.cjs music.test.cjs
```

사이트의 `volume.yaml` 등록과 커밋·발행은 별도 단계입니다. 성장 장면 진입 때 박 상태를 초기화하고, 닫힌 박은 분할 없이 한 장으로 그립니다.

자유 연주 화면에는 창작곡 5개가 바로 표시됩니다. 곡 버튼을 한 번 누르면 재생하고, 다른 곡을 누르면 전환하며, 재생 중인 곡을 다시 누르면 멈춥니다. 곡 버튼에 초점을 둔 Enter/Space도 동일하게 동작합니다.
