# 〈MZ 같지 않네요〉

금요일 저녁 모임에서 지윤의 친절은 칭찬이 되고, 더해진 부탁 앞에서 기대와 세대 평가로 바뀐다. 관객은 산호색 말을 세 번 걷어내며 지윤의 지난 기억과 막차까지 남은 시간을 본다. 마지막에는 평가 대신 이름을 부르는 인사가 남는다.

`index.html`이 실제 작품의 진입점이다. 인물과 공간은 `motion-art.js`의 Canvas 2D, 종이와 잔상은 `experience.js`의 Canvas 2D, 시간과 전환은 로컬 GSAP으로 구성한다. 음악·세 인물의 한국어 대사·폰트까지 에셋은 모두 작품 폴더에 있으며 외부 요청은 없다. 출처와 생성 조건은 `ASSETS.md`에 기록했다.

종이는 마우스·터치로 끌거나 탭, Enter/Space로 걷는다. 자동 진행 부분은 약 90초이고 세 종이 앞에서는 관객을 기다린다. 음소거는 음악·대사·효과음에 함께 적용된다. 일시정지, 탭 숨김, 움직임 줄이기를 지원하며 무음에서도 이야기를 읽을 수 있다.

Node 22.12 이상에서 `npm ci && npm run build` 후 `/vol/2-mz/ch/1-mz-gatji-anhneyo/`에서 볼륨 안의 작품을, `/chapters/2-mz/1-mz-gatji-anhneyo/index.html`에서 작품만 확인할 수 있다. 1440×900, 390×844, 375×667 크기와 실제 sandbox iframe에서 전체 재생·입력·소리·재시작을 검사했다.
